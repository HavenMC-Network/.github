## 🟣 About HavenMC

HavenMC is a Minecraft network featuring gamemodes such as HCF, Kitmap, Practice, and much more!
Join our server or Discord using the information above.

## 🛠️ Development

All non-open-source repositories belonging to HavenMC are not available for redistribution or external use.

HavenMC's codebase and plugins are mainly developed and maintained by me, **[clouds](https://github.com/clquds)**.

Interested in contributing to HavenMC? Create a ticket in our Discord.
